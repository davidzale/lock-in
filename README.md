# LOCK IN

Personal life tracker — daily habits, goals, calendar, finance, sport, growth and stats. Installable PWA for iPhone.

## Run locally

```bash
npm install
npm run dev
```

## Install on iPhone

1. Open the GitHub Pages URL in **Safari**.
2. Share → **Add to Home Screen**.
